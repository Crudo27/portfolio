# Maestros artísticos de la secuencia

Esta carpeta conserva únicamente los tres originales únicos para futuras revisiones de la ilustración:

- `sources/hero-original.png`: pintura de referencia del Hero.
- `sources/contact-master-approved-desktop.png`: escena final aprobada de escritorio.
- `sources/contact-master-approved-mobile.png`: escena final aprobada de móvil.

La aplicación utiliza exclusivamente los160 fotogramas completos, manifiesto y geometrías de `../public/portfolio-scroll/`. Los originales no se modifican ni se montan como personajes separados. Las instrucciones de instalación y los ejemplos de los kits ya sustituidos se retiraron.

Para ejecutar, compilar y mantener el portfolio, seguir el README de la raíz y DESIGN.md. Las limitaciones de la disolvencia original se documentan en `../docs/validation.md`.
